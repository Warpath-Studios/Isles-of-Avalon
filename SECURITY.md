# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, exploit, duplication bug, authentication issue, or anything else that could be used to harm live servers, other players, or player data, **please do not report it publicly** — not in issues, discussions, pull requests, Discord, or any other public channel.

Instead, report it privately to:

**security@[PLACEHOLDER — final address to be provided by Warpath Studios]**

Please include:

- A clear description of the issue
- Steps to reproduce it, if possible
- The game version and platform you're on
- Any relevant logs or screenshots (with personal information redacted)

We ask that you give us a reasonable amount of time to investigate and address the issue before discussing it publicly, and that you avoid actions that could disrupt live servers or other players while reporting.

## What not to post publicly

Please do **not** post any of the following in public issues, discussions, or pull requests:

- Exploits or duplication bugs
- Authentication or account-security issues
- Server vulnerabilities or ways to disrupt live servers
- Passwords, authentication tokens, private server keys, or API keys
- Other players' personal information

Reports containing this kind of information will be removed, and we'll follow up with you privately where possible.

Thank you for helping keep Isles of Avalon and its community safe.
