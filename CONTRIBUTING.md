# Contributing

Thanks for your interest in Isles of Avalon. Please read this before opening an issue or pull request.

## This is not an open-source game repository

Isles of Avalon's game source, plugins, and internal architecture are closed-source and developed privately by Warpath Studios. This public repository does not contain the game project, and we are not accepting code contributions to the game itself.

## What contributions are welcome

Unless we say otherwise for a specific initiative, contributions here are limited to:

- Corrections to public documentation (typos, unclear instructions, broken links)
- Improvements to community-facing materials (e.g. modding docs, server setup guides), where explicitly opened for community input

If you're unsure whether something is in scope, please open an issue first to ask before submitting a pull request.

## Reporting bugs and requesting features

Please don't open ad-hoc issues for bugs or feature ideas — use the templates:

- [Bug report](.github/ISSUE_TEMPLATE/bug_report.yml)
- [Feature request](.github/ISSUE_TEMPLATE/feature_request.yml)
- [Dedicated server issue](.github/ISSUE_TEMPLATE/server_issue.yml)

This helps us triage things consistently and make sure we have the information we need.

## Security issues

Do not report security vulnerabilities, exploits, or duplication bugs through public issues. See [SECURITY.md](SECURITY.md).

## Code of conduct

Be respectful. We reserve the right to close issues or pull requests, and to restrict participation, for behavior that is abusive, spammy, or otherwise not constructive.
