# Isles of Avalon

**Isles of Avalon** is a multiplayer survival and settlement game built on Unreal Engine, developed by **Warpath Studios**. Players explore, gather, build, farm, tame animals, and grow settlements together in a persistent shared world.

The game is currently **in active development**. Features described in this repository's roadmap represent planned or in-progress work and are subject to change.

## What this repository is for

This is the **public-facing repository** for Isles of Avalon. It exists so players and community members can:

- Follow public announcements and progress updates
- Read public-facing documentation (dedicated servers, modding, etc.)
- Report bugs using our [issue templates](.github/ISSUE_TEMPLATE)
- Submit feature requests and feedback
- Track the public [roadmap](ROADMAP.md), [changelog](CHANGELOG.md), and [known issues](KNOWN_ISSUES.md)

## What this repository is NOT

This repository does **not** contain the game's source code, plugins, proprietary assets, or internal architecture documents. Isles of Avalon is closed-source; all game development happens in a private repository. Nothing in this repository should be interpreted as an invitation to contribute to or modify the game's codebase.

See [CONTRIBUTING.md](CONTRIBUTING.md) for what kinds of contributions are welcome here, and [SECURITY.md](SECURITY.md) for how to report security concerns responsibly.
