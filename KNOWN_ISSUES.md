# Known Issues

This page tracks publicly known issues in the current build of Isles of Avalon. It is manually curated and updated periodically — it is not a full internal bug tracker.

**Do not use this page to report security vulnerabilities, exploits, or duplication bugs.** See [SECURITY.md](SECURITY.md) for how to report those privately.

## How to read this list

Each entry includes the affected area, a short description, and current status.

| Area | Issue | Status |
|---|---|---|
| _Example: Dedicated Servers_ | _Example: players occasionally desync after long sessions_ | _Investigating_ |

## Status definitions

- **Investigating** — we're aware and looking into it
- **Confirmed** — reproduced and understood, fix planned
- **Fix in progress** — actively being worked on
- **Resolved** — fixed in a recent or upcoming update

---

If you've found an issue not listed here, please [open a bug report](.github/ISSUE_TEMPLATE/bug_report.yml) using our issue template.
