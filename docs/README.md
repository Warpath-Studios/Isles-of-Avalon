# Documentation

This is the public documentation hub for Isles of Avalon. It covers player-facing topics like running dedicated servers and modding support.

## Contents

- [Dedicated Servers](dedicated-servers.md) — how to set up and run your own server
- [Modding](modding.md) — what modding support exists (or is planned) and how to get involved

This documentation is maintained separately from the game's internal development documentation, which is private. If something here is unclear or out of date, please [open an issue](../.github/ISSUE_TEMPLATE) or submit a documentation correction per [CONTRIBUTING.md](../CONTRIBUTING.md).
